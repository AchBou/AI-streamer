# VRM Models Folder

Place your VRM model files in this directory.

## How to Add Models

There are two ways to add VRM models to the application:

1. **Drag and Drop**: Simply drag and drop a VRM file onto the application window. The model will be loaded immediately, and a button will be created for it in the "Models" section.

2. **Copy Files**: Copy your VRM model files directly into this folder. When you restart the application, buttons for these models will appear in the "Models" section.

## Finding VRM Models

You can find VRM models from various sources:
- VRoid Hub (https://hub.vroid.com/)
- The Seed Online (https://seed.online/)
- VRM Consortium (https://vrm-consortium.org/)

## Building the Project

When you build the project, these models will be copied to the dist folder and will be available for loading in the application.

## Important Note

Some VRM models may have usage restrictions. Please respect the creators' terms of use.
